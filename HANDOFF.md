## 3. Render rules (from the owner's feedback, do not break)

- **Chamfers:** only where the official drawing has them. Nothing gets generic bevels.
- **Corner chamfer:** it cuts through **every layer** at that corner (top board, cross board, block and bottom board). Sizes are EPAL 1 17 mm, EPAL 2/3 24 mm and CP 20 mm, all at 45°.
- **Outer bottom boards of EPAL-type pallets:** chamfered only between the blocks, on the outer top edge, about 11 mm deep with curved run-outs. The pinewood middle bottom board has no chamfer.
- **GMA notches:** rounded, about 230 × 38 mm with a radius of about 32 mm, not rectangles.
- **Dimensions:** every component was checked against the official EPAL / CP drawings, which are free on epal-pallets.org. Board and block counts match for EPAL 1–3 and CP1–CP7.
- **EPAL marking positions (Pallet Euro only), from EPAL's own sheets:**
  - EPAL 1, 2 and 3: the EPAL oval on the left AND right corner blocks, and the IPPC mark (plus licence number, year and month) on the centre block.
  - CP1–CP9: the IPPC mark on the left-hand corner block, the CP type and EPAL ID on the centre block, and the EPAL oval on the right-hand corner block.
- Which marks go on the pallets is set in `tools/render/brand.json` (one per repo), and the stamps are generated by `make_stamps.py`.

## 4. How the render pipeline works

- **Blender:** 5.x at `/Applications/Blender.app`, run headless. Cycles uses the METAL GPU only; adding the CPU made it about 7× slower.
- **Run it:**
  - `npm run render` renders everything: about 33 min for Ambica and 16 min for Pallet Euro on an M2 Pro.
  - `npm run render -- <slug>` renders one product.
- **Pallet layouts:** `tools/render/pallets.py` lists every board, block and stringer in millimetres. Running it prints a check table, and every row must say `ok`.
- **Renderer:** `tools/render/render_pallet.py` produces 5 views (4 for the collar) on a #F2F2F2 background.
  - View 9 is a close-up of one marking: `--views 9 --detail-index N`.
  - `--glb` also exports the web 3D model.
- **Textures:** CC0 wood textures from ambientCG (Wood096 pine, Wood060 hardwood), downloaded by `tools/render/fetch_textures.sh`. Never open the .blend files inside those zips.
- **Output:** WebP images go to `src/assets/products/<slug>/`. Ambica's GLBs go to `public/models/`.

## 8. Setting up the new Mac

Everything needed is in the two GitHub repos. The following is NOT in git and is either regenerated or reinstalled:

| Not in git | What to do |
|---|---|
| `node_modules/`, `dist/`, `.astro/` | `npm install`, then `npm run build` |
| `tools/render/textures/` (21 MB) | Downloaded automatically by `tools/render/fetch_textures.sh` the first time you render |
| `tools/render/out/` (full-size PNG renders) | Not needed; the website uses the WebP copies that are in git |
| Claude's memory notes (in `~/.claude/projects/…/memory/`) | Their content is in sections 2–5 of this file |
| Software | Node 22.22+, Git, Blender 5.x (only to re-render), `brew install webp` for `cwebp` (only to re-render), Google Chrome |

```bash
mkdir -p ~/VSC/APIPL && cd ~/VSC/APIPL
git clone https://github.com/WeWake1/apiplSite.git
git clone https://github.com/WeWake1/PalletEuro.git palletEuroSite
cd apiplSite && npm install && npm run build        # Ambica
cd ../palletEuroSite && npm install && npm run build # Pallet Euro
```

Cloning Pallet Euro into a folder called `palletEuroSite` keeps the same layout as the old Mac.
